# TraumChatRoom 阿里云部署指南

> 适用环境：Ubuntu 24.04 轻量服务器（2核2G/40G，swap 2G），1Panel 面板 + OpenResty 反向代理
> 技术栈：Spring Boot 4.0.5 (Java 21) + Vue 3/Vite 8 + MySQL 8.0.46 + Redis 8.6.3 + WebSocket (STOMP/SockJS)
> 部署方式：传统手动部署（systemd 守护 jar + OpenResty 托管前端并反代）

## 目标架构

```
浏览器 → https://你的域名
           │
   1Panel OpenResty (80/443) 托管 frontend/dist + 反代
           ├── /api/*  → 127.0.0.1:8080
           └── /ws/*   → 127.0.0.1:8080 (WebSocket 升级)
                                │
                     Spring Boot jar (systemd 守护, 仅回环)
                                │
                  MySQL 8.0.46 (ChatRoomDB) + Redis 8.6.3
```

## 阶段 1 — 本地代码修改（3 处，必改）

**① `src/main/resources/application.yml:38`** — `file.upload-dir` 改为环境变量注入：
```yaml
file:
    upload-dir: ${FILE_UPLOAD_DIR:/home/traums/javaword/uploads}
```
> 生产通过环境变量注入 `/home/traums/javawork/uploads`，消除硬编码 Windows 路径。

**② `src/main/resources/application.yml:71`** — CORS 白名单改为可注入：
```yaml
cors:
  allowed-origins: ${CORS_ALLOWED_ORIGINS:http://localhost:5173,http://localhost:3000}
```

**③ `ChatRoomVue/.env.production`** — 改为真实域名：
```
VITE_API_URL=https://你的域名
```
> 前端 axios 与 WebSocket 均使用该值（`useWebSocket.js:38` 拼接 `${baseUrl}/ws`），同源走 OpenResty，无跨域问题。

> 无需修改 `application-prod.yml`，它已声明从环境变量读取 `DB_URL / DB_USERNAME / DB_PASSWORD / REDIS_HOST / REDIS_PORT / REDIS_PASSWORD / AI_API_KEY / JWT_SECRET`。`application-dev.yml` 中的硬编码密钥仅供本地联调，不影响生产。

## 阶段 4 — 后端部署（backend 目录）

**① 创建 `.env`** `/home/traums/javawork/backend/.env`：
```bash
sudo tee /home/traums/javawork/backend/.env >/dev/null <<'EOF'
# 数据库
DB_URL=jdbc:mysql://localhost:3306/ChatRoomDB?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
DB_USERNAME=traums
DB_PASSWORD=新密码_替换我
# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_DATABASE=5
REDIS_PASSWORD=你的redis密码
# 安全
JWT_SECRET=你的32字节Base64密钥
CORS_ALLOWED_ORIGINS=https://你的域名
# AI
AI_API_KEY=你的DeepSeekKey
# 文件
FILE_UPLOAD_DIR=/home/traums/javawork/uploads
EOF
sudo chmod 600 /home/traums/javawork/backend/.env
```

- `JWT_SECRET` 生成命令：`openssl rand -base64 32`（项目要求 Base64 解码后 32 字节）
- `REDIS_PASSWORD`：Redis 已设密码则填实际值，未设则留空
- systemd EnvironmentFile 中的 `!` 等特殊字符无需 shell 转义

**② systemd 服务** `/etc/systemd/system/traumchat.service`：
```ini
[Unit]
Description=TraumChatRoom Spring Boot
After=network.target mysql.service redis-server.service

[Service]
User=traums
Group=traums
WorkingDirectory=/home/traums/javawork/backend
EnvironmentFile=/home/traums/javawork/backend/.env
ExecStart=/usr/lib/jvm/java-21-openjdk-amd64/bin/java -Xms256m -Xmx512m -jar /home/traums/javawork/backend/traumchat.jar --spring.profiles.active=prod --server.address=127.0.0.1
Restart=on-failure
RestartSec=10
SuccessExitStatus=143

[Install]
WantedBy=multi-user.target
```

> JDK 实际路径用 `readlink -f $(which java)` 确认后替换。
> `--server.address=127.0.0.1`：只监听回环，公网安全组不开 8080。

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now traumchat
sudo systemctl status traumchat
journalctl -u traumchat -f    # 启动日志；文件日志在 backend/logs/app-*.log
```

## 阶段 5 — 前端 + 1Panel OpenResty 反代

1. 在 1Panel 面板创建**网站**，类型「静态网站」，域名填你的域名，根目录选 `/home/traums/javawork/frontend`。
2. 打开该网站的**配置文件**（或编辑站点 nginx conf），在 server 块中加入：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 120s;
}

location /ws/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;      # WebSocket 升级头，必须
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 300s;
}
```

> **关键**：1Panel 面板默认反代不带 WebSocket 升级头，`/ws/` 必须手写 `Upgrade/Connection`，否则 STOMP/SockJS 连不上。SockJS 会先发 HTTP 探测请求再升级，上述配置两者兼容。

3. 重载 OpenResty：1Panel 面板点「重载」或 `docker exec 1Panel-openresty nginx -s reload`。
4. 阿里云安全组放行 **80、443**（8080 不开放）。

## 常见故障对照

- **前端白屏** → 检查 OpenResty 站点根目录指向 `frontend`、`dist` 是否已解压为 `index.html` 层级。
- **WS 连不上** → 99% 是 `/ws/` 少了 `Upgrade/Connection` 头。
- **登录 500 / 连库失败** → 查 `backend/logs/app-error-*.log`，确认 `.env` 的 DB 参数与 MySQL8 `caching_sha2_password`（URL 已带 `allowPublicKeyRetrieval`）。
- **OOM** → 看 `systemctl status traumchat`；JVM 512M + MySQL buffer_pool 调 256M（`/etc/mysql/mysql.conf.d/mysqld.cnf`）+ swap 2G 兜底。
