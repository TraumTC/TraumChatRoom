## 2. 四大核心链路

### 链路 A：认证（注册 / 登录 / 刷新 / 游客 / 登出）

```
注册    AuthServiceImpl.register   : 查重用户名+昵称 → BCrypt → insert(status=1, ROLE_USER)
登录    AuthServiceImpl.login      : 检查用户/IP 锁 → 校验密码 → 查状态 → 清失败计数 → cacheUser → 双令牌
刷新    AuthServiceImpl.refresh    : validateToken → Redis 存 token 比对 → 重新生成双令牌
游客    AuthServiceImpl.loginAsGuest: GuestNameUtil 生成 guest_{ts}_{rand} → 全量存 Redis(2h) → 双令牌(access 1d / refresh 2h)
登出    AuthServiceImpl.logout     : 删 Redis chat:refresh:{username}
当前    AuthServiceImpl.getCurrentUser: 先 DB 后 Redis 游客
```

入口：`AuthController`。JWT 校验：`JwtAuthenticationFilter` → `UserDetailsServiceImpl.loadUserByUsername`（游客从 Redis 构造，普通用户查 DB）。

### 链路 B：群聊 + AI @小汤

```
发送    WebSocketChatController.sendGroupMessage (/app/space)
        → 长度校验(≤2000) → 查发送者(DB/Redis游客) → 敏感词过滤(blocked→send-error, replaced→替换)
        → 组 Message → insert → 广播 /topic/messages → 若含@小汤且非游客 → triggerAiReply

AI     triggerAiReply: Thread.startVirtualThread → aiService.getAiReply(query, "group")
        → Redis 限流(chat:ai:rate:group, 3/min) → 查上下文(DB最近5轮) → 调 DeepSeek
        → 存上下文(DB, 保留20条) → 确保 ai_xiaoai 存在 → insert AI消息 → 广播

历史    ChatServiceImpl.getGroupHistory: 游标分页, ORDER BY id DESC, size+1 判断 hasMore
撤回    ChatServiceImpl.recallMessage: @Transactional, 权限(本人/管理员) + 2分钟内
        → content 替换"xx 撤回了一条消息", 原文存 original_content → 广播
```

### 链路 C：私聊 + 好友

```
私聊发送 WebSocketChatController.sendPrivateMessage (/app/private.message)
        → 游客拒绝 → 长度校验 → 敏感词 → insert → 推双方 /user/{name}/queue/private-messages
私聊历史 ChatServiceImpl.getPrivateHistory: 游客禁查, 双向匹配查询
好友搜索 FriendServiceImpl.searchUsers: 关键词 → 每条3次状态判断(朋友/待发/待收)
好友申请 FriendServiceImpl.sendRequest: 非自己 → 非好友 → 无 pending → insert → WS 通知
处理申请 FriendServiceImpl.handleRequest: 仅接收者 → accept: 更新状态+双向两条好友+删缓存+WS; reject: 状态2
好友列表 FriendServiceImpl.getFriends: 分页, 每好友一次 findById + isOnline
备注/删除 FriendServiceImpl.updateRemark / deleteFriend(@Transactional 双向删)
```

### 链路 D：管理后台

```
用户管理 AdminController.updateRole/updateUser/deleteUser → 直接改 DB（未见 evictUser）
敏感词   AdminController.addSensitiveWord/deleteSensitiveWord/refreshSensitiveWords → 改 DB + SensitiveWordFilter.refresh()
日志     OperationLogAspect(@AfterReturning) → operation_log 表
```

## 3. 关键状态机

### 3.1 好友申请状态
`friend_request.status`: `0=待处理 → 1=已同意 / 2=已拒绝`；30 天过期 = **声明但未实现**。

### 3.2 消息撤回
`is_recalled: 0→1`；时间窗 `created_at + 2 分钟`（硬编码）。对外 content 替换为 `"{senderName} 撤回了一条消息"`，原内容保留 `original_content`（管理员可见）。

### 3.3 游客生命周期
Redis 2h 过期 → JWT 失效后 `loadUserByUsername` 抛异常 → 前端 401 流程。**游客信息(TTL 2h) 与 accessToken(1d) 生命周期不一致**。

### 3.4 在线状态
Redis ZSet `chat:online:{?}`，score=最后心跳时间，5 分钟超时窗口；上线/下线/心跳由 WS 驱动。

### 3.5 AI 触发
`@小汤|@AI|@ai|@Ai` 正则命中即触发；sessionKey 固定为 `"group"`（**全群共享**上下文与限流）。
